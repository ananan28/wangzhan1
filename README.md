# Daisy VC Personal Website

这是一个高端极简、响应式的单页风险投资个人介绍网站。

## 使用方法
1. 直接双击 `index.html` 即可在浏览器预览。
2. 修改页面中的：
   - 联系邮箱 `diasykhoo118@gmail.com`
   - 个人介绍、履历和投资案例
3. 可部署到：
   - GitHub Pages
   - Vercel
   - Netlify
   - Cloudflare Pages

## 设计特点
- 深色高端视觉
- 移动端适配
- 轻量原生 HTML / CSS / JavaScript
- 无框架依赖
- SEO 基础标签
- 动效与无障碍适配
